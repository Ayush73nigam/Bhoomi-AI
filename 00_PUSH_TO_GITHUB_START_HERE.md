## 🆘 Troubleshooting Quick Links

**Problem:** Git not found
- **Solution:** Download from https://git-scm.com/download/win

**Problem:** "fatal: repository not found"
- **Solution:** Check URL and GitHub access permissions

**Problem:** "fatal: permission denied"
- **Solution:** Use GitHub personal access token instead of password

**Problem:** "fatal: branch 'main' does not exist"
- **Solution:** Try pushing to `master` instead

- **Solution:** See "GITHUB_PUSH_MANUAL.md" for command-prompt alternative
