================================================================================
                    TROUBLESHOOTING GUIDE
================================================================================

ISSUE 1: "Address already in use" error
CAUSE: Port 5000 is already in use
SOLUTION:
  Option A: Wait 30 seconds and try again
  Option B: Find and kill process: netstat -ano | findstr 5000
  Option C: Edit start_server.py, change port to 5001

ISSUE 2: "No module named 'requests'"
CAUSE: requests package not installed
SOLUTION: pip install requests

ISSUE 3: "ModuleNotFoundError: No module named 'flask'"
CAUSE: Flask not installed
SOLUTION: pip install flask

ISSUE 4: "Model not found at models/rf_model.pkl"
CAUSE: Model file hasn't been trained
SOLUTION: python calculate_accuracy.py (takes 5-10 minutes)

ISSUE 5: "Zone data not loading"
CAUSE: dataset/agro_zones.json not found or corrupted
SOLUTION:
  - Check file exists: ls dataset/agro_zones.json
  - Validate JSON: python -m json.tool dataset/agro_zones.json

ISSUE 6: "Templates not found"
CAUSE: templates/ folder missing or files missing
SOLUTION:
  - Ensure templates/ folder exists
  - Required files: index.html, predict.html, crops.html, about.html

ISSUE 7: Unicode/Encoding errors
CAUSE: Windows console encoding issue
SOLUTION:
  - Use test_server_quick.py (handles encoding)
  - Or set: set PYTHONIOENCODING=utf-8

ISSUE 8: Server crashes immediately
CAUSE: Model or data loading error
SOLUTION:
  - Check error message in console
  - Verify model: python -c "import pickle; pickle.load(open('models/rf_model.pkl', 'rb'))"
  - Verify zones: python -c "import json; json.load(open('dataset/agro_zones.json'))"
