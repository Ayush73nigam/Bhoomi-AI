================================================================================
                    IF SOMETHING GOES WRONG
================================================================================

ERROR: "Address already in use"
  Cause: Port 5000 is taken
  Fix: Close other apps using port 5000, or wait 30 seconds

ERROR: "No module named..."
  Cause: Package not installed
  Fix: pip install <package-name>
  Example: pip install flask scikit-learn pandas numpy requests

ERROR: "Model not found"
  Cause: ML model hasn't been trained
  Fix: python calculate_accuracy.py (takes 5-10 minutes)

ERROR: "Zone data not loading"
  Cause: Dataset file missing or corrupted
  Fix: Check dataset/agro_zones.json exists, is readable JSON

ERROR: "Templates not found"
  Cause: HTML templates missing
  Fix: Ensure templates/ folder has: index.html, predict.html, crops.html, about.html

For more help:
  1. Read FLASK_SERVER_STARTUP_README.txt
  2. Check error message in terminal
  3. Review SERVER_STARTUP_VERIFICATION.txt
