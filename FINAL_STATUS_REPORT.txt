================================================================================
                      API USAGE EXAMPLES
================================================================================

REST API Endpoint: POST http://localhost:5000/api/predict

Python Example:
────────────────────────────────────────────────────────────────────────────
import requests

url = "http://localhost:5000/api/predict"
data = {
    "tmin": 15, "tmax": 28,        # Temperature range (°C)
    "rmin": 2, "rmax": 15,         # Rainfall range (cm)
    "stmin": 18, "stmax": 32,      # Sowing temperature
    "htmin": 12, "htmax": 25,      # Harvest temperature
    "sand": 40, "clay": 25, "silt": 35,  # Soil composition (%)
    "nitrogen": 150,               # N fertilizer (kg/ha)
    "phosphorus": 80,              # P fertilizer (kg/ha)
    "potassium": 60,               # K fertilizer (kg/ha)
    "humidity": 65,                # Humidity (%)
    "ph": 6.5,                     # Soil pH
    "season": "Rabi",              # Season: Rabi or Kharif
    "zone_id": 4                   # Zone: 0-14 (optional)
}

response = requests.post(url, json=data)
result = response.json()

print(f"Recommended Crop: {result['crop']}")
print(f"Confidence: {result['confidence']}%")
print(f"Zone: {result['zone_name']}")


JavaScript/Fetch Example:
────────────────────────────────────────────────────────────────────────────
const data = {
    tmin: 15, tmax: 28, rmin: 2, rmax: 15,
    stmin: 18, stmax: 32, htmin: 12, htmax: 25,
    sand: 40, clay: 25, silt: 35,
    nitrogen: 150, phosphorus: 80, potassium: 60,
    humidity: 65, ph: 6.5,
    season: "Rabi", zone_id: 4
};

fetch('http://localhost:5000/api/predict', {
    method: 'POST',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify(data)
})
.then(r => r.json())
.then(result => {
    console.log(`Crop: ${result.crop}`);
    console.log(`Confidence: ${result.confidence}%`);
})

================================================================================
                      ERROR HANDLING & RECOVERY
================================================================================

Handled Errors:

1. Missing Model:
   - Returns fallback heuristic predictions
   - Uses ICAR agroclimatic guidelines
   - Still provides crop recommendations

2. Missing Zone Data:
   - Returns empty zones/states list
   - Uses default zone (4) for predictions
   - Form still functional with defaults

3. Invalid Input:
   - Returns 400 error with description
   - Validates all numeric inputs
   - Checks zone_id range (0-14)

4. Unknown State/District:
   - Returns 404 error
   - Suggests using default zone
   - API still functional

5. Invalid API Request:
   - Returns 415 for wrong Content-Type
   - Returns 400 for missing fields
   - Provides error message details

Automatic Fallbacks:
  - Missing season → defaults to Kharif
  - Missing zone → defaults to Zone 4
  - Invalid float → zeros out
  - Graceful degradation maintained
