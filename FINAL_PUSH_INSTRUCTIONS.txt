================================================================================
                         TROUBLESHOOTING
================================================================================

ISSUE: "git: command not found"
SOLUTION: Git is not installed
- Download: https://git-scm.com/download/win
- Install and restart your computer

ISSUE: "fatal: repository not found"
SOLUTION: Check GitHub repository URL
- Verify: https://github.com/karan-nigam96/Bhoomi_AI.git is correct
- Check: You have access to the repository

ISSUE: "fatal: permission denied"
SOLUTION: Authentication issue
- Method 1: Use GitHub personal access token (recommended)
- Method 2: Setup SSH keys
- See: https://docs.github.com/en/authentication

ISSUE: "fatal: 'main' does not appear to be a 'git' repository"
SOLUTION: Try master branch instead
- Command: git push -u origin master

ISSUE: "The remote end hung up unexpectedly"
SOLUTION: Internet or network issue
- Check: Internet connection is active
- Wait: Few minutes and try again
- Try: Force push (only if you're the owner)

FOR MORE: See GITHUB_PUSH_MANUAL.md for detailed troubleshooting
